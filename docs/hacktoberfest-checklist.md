# Hacktoberfest 2026 preparation

Hacktoberfest 2026 ("AI belongs to everyone") is run by MLH and DEV, presented by DigitalOcean. **Pull requests no longer count toward rewards**; participants collect virtual stickers by attending Fests and livestreams, entering DEV Challenges, joining Global Hack Week: Hacktoberfest and using a few tools. Three stickers earn a mailed sticker pack. Source: [hacktoberfest.com](https://hacktoberfest.com) (re-check before relying on dates or sticker counts; they changed during Preptember).

MatchMind targets the [Hacktoberfest 2026 Weekend Challenge — Build for a Friend](https://dev.to/challenges/hacktoberfest-weekend-2026-10-01): October 2, 02:00 UTC → October 5, 06:59 UTC (October 5, 03:59 in São Paulo). Submission tag: `hf26challenge`. The weekly **Open-Source AI Challenge** rounds (Weeks 1–4, from October 5) are further options. Check each challenge page for the current prompt, rules and eligibility.
